# <img width="64" height="64" alt="LogoBox64px" src="https://github.com/user-attachments/assets/5b21fc20-f7d2-4e88-81d3-59ca1db97446" />⭐RomMStar⭐


RomMStar Plugin syncs your local Launchbox installations with RomM servers, giving you a Storefront-like experience for rom collections

## Intro

RomM is a self-hosted rom collection manager that helps build a single 'canon' set of roms for each platform. You can then sync these collections with any Launchbox installation (either downloading the full set or only installing the games you want on demand - a bit like the Storefronts experience)

It's designed to be simple and easy-to-use. Just add the RomM server (yours or someone else's), match the Launchbox Platform to that on the RomM server and Sync.

## Install

Unzip the RomMStar Folder to the Launchbox/Plugins folder.

## Top Tips

This hasn't been fully tested with the Launchbox auto-import function turned on. Turn it off to be safe or do some testing if you want to keep this on

Make sure the RomM server scrapes with Launchbox as a Metadata Source (ie. games have the LaunchboxID). This prevents duplicates during sync

If you want to enable RomMStar badges in BigBox, you will have to turn this on in the RomMStar settings menu

For best results, sync to a 'clean' Launchbox Platform. If you mix local with synced roms, you may experience difficulties.
